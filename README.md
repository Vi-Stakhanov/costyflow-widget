# Costyflow Widget

Плавающая кнопка-виджет для сайта клиента. Открывает калькулятор Costyflow в новой вкладке.

## Установка

1. Скопировать содержимое `widget.html`.
2. Вставить перед закрывающим тегом `</body>` на сайте клиента.
3. Заменить ссылку `https://yourcompany.costyflow.ru` на поддомен клиента.

## Что можно изменить

- **Цвет кнопки** — свойство `background` в `.cf-widget` (по умолчанию `#0039d1`).
- **Размер** — `width` / `height` в `.cf-widget` (по умолчанию 60×60px).
- **Позиция** — `right` / `bottom` в `.cf-widget` (по умолчанию правый нижний угол).

## Требования

Любой сайт, где можно добавить HTML перед `</body>`: WordPress, Битрикс, Tilda, Next.js, самопис.
